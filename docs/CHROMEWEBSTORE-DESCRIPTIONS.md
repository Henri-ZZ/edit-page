# Chrome Web Store Descriptions — Edit Page

> English is the default locale. All other languages are ordered alphabetically by their English language name.

## English (en)

```text
Edit any webpage directly in your browser—without changing the original website. Edit Page is useful for mockups, content review, design previews, presentations, and clean screenshots.

FEATURES

• Edit visible text directly on the page.
• Replace images from your device or an Image URL.
• Remove unwanted page elements.
• Undo and redo your editing changes.
• Capture the current viewport or a full-page screenshot.
• Copy screenshots to the clipboard or download them as PNG files.
• Optionally hide floating elements, repeated content, and scrollbars during full-page capture.

Changes are temporary and stay in your browser. Refresh the webpage to restore the original page. Some browser-controlled or protected pages cannot be edited.
```
