# Chrome Web Store Descriptions — Edit Page

> English is the default locale. All other languages are ordered alphabetically by their English language name.

## English (en)

```text
Edit Page lets you edit webpages directly in your browser. Quickly edit text, change images, remove elements, and capture screenshots without leaving the page.

Whether you're creating a quick mockup, testing a design idea, preparing a presentation, or simply want to see how a webpage could look with different content, Edit Page makes temporary webpage editing simple.

What you can do

Edit text
Click text on a webpage and replace it with your own content. Edit Page is designed for quick text changes and does not require coding.

Change image
Replace images on a webpage with a local image or an Image URL. Preview the replacement before applying it.

Remove element
Click an element on the page to remove it and create a cleaner version of the webpage.

Screenshot
Capture your edited page as a Current viewport screenshot or a Full page screenshot. Save screenshots to the Clipboard or Download them.

Undo & Redo
Easily undo or redo your changes while editing, so you can experiment without worrying about losing your previous work.

Perfect for

Creating quick webpage mockups
Testing different text and images
Preparing presentation screenshots
Creating visual drafts and concepts
Demonstrating webpage changes
Quickly removing unwanted page elements

Edit Page is available for Chrome and Microsoft Edge.

Start editing a webpage in seconds — no coding required.
```
